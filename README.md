# 🍽️ Restaurant Website

Еlegant website for a restaurant, designed to showcase menus, services, and atmosphere.

## 🚀 Live Demo
You can view the live project here:  
🔗 **[Live Demo Link](https://jimmyhyusein.github.io/restaurant-website/)**

## ✨ Features
- **Interactive Menu:** Clean display of dishes and prices.
- **Reservation Form:** Easy-to-use interface for booking tables.
- **Smooth Navigation:** One-page layout with smooth scrolling.

## 🛠️ Technologies Used
- **HTML5** & **CSS3** (Flexbox/Grid)
- **JavaScript** (ES6+)
